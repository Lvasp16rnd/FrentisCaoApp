# 🐾 FrentisCão

Aplicativo mobile para facilitar o contato entre **ONGs de proteção animal**, **protetores independentes** e **doadores**.

## Stack Tecnológica

| Camada | Tecnologia |
|---|---|
| **Frontend** | Flutter (Dart) |
| **Arquitetura** | MVVM com Provider |
| **Backend** | Supabase (PostgreSQL) |
| **Navegação** | go_router |
| **Tipografia** | Google Fonts (Inter + Roboto) |

## Como Rodar

```bash
flutter pub get
flutter run
flutter analyze
```
